# Microfinance IS

Information system for managing loan applications and repayments.
Team project for the course **Basics of Information Systems, Fall 2026**.

## About the project
Microfinance IS helps a microfinance organization handle its core lending workflow:
- submitting and reviewing loan applications;
- approving or rejecting loans;
- tracking repayment schedules and payments;
- reporting on the state of the loan portfolio.
